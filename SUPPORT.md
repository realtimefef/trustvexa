# Support

Thanks for using TrustVexa. Here is how to get help.

## Documentation first

- **[README](README.md)** — setup, configuration, and an overview of the platform.
- **[Architecture](docs/ARCHITECTURE.md)** — how the system fits together.
- **[Security hardening](docs/security-hardening.md)** and
  **[Incident response](docs/incident-response.md)** — production operations.
- **Product spec** — `kiro/specs/trustvexa-escrow-platform/`.

## Questions & discussion

- Use **GitHub Discussions** (if enabled) for usage questions and ideas.
- Search existing issues before opening a new one — your question may already be
  answered.

## Bug reports & feature requests

- Open a **GitHub Issue** using the appropriate template.
- Include reproduction steps, expected vs. actual behavior, and environment details.

## Security issues

**Do not** use public issues for vulnerabilities. Follow the private process in
[SECURITY.md](SECURITY.md).

## Operational / account support

For account, deal, or payment support on a running deployment, contact the operator’s
support channel (replace with the real address): **support@trustvexa.com**.
